# -HandyVision-
Real-Time Hand Tracking &amp; Gesture Detection
HandyVision is a beginner-friendly, real-time hand tracking project built using Python, OpenCV, and CVZone. This tool detects your hand from a webcam feed, identifies fingers that are up, and even measures the distance between them – all live on screen!

Whether you're just starting out with computer vision or looking to integrate gesture controls into your apps or games, this project is a simple and fun way to get started with hand gesture recognition.

🚀 Features
📷 Real-time webcam hand tracking

✌️ Detects how many fingers are up

📏 Measures distance between fingertips (e.g., index & middle finger)

🖥️ Visual overlays to show bounding boxes, landmarks, and distances

🔄 Auto-flips camera feed for a more intuitive experience

🛠️ Tech Stack

OpenCV
